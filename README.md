# OGgames

A small collection of browser games with an animated intro and a games hub.

**Games**
- Verity Clicker: a Cookie Clicker-style idle game with helpers, upgrades, spells, golden Verity and ascension.

## Run it
It is a static site. Open `index.html` in a browser, or host the folder on GitHub Pages, Netlify or Cloudflare Pages.

Keep `index.html` and `intro.mp4` in the same folder. Game progress is saved in each visitor's own browser.
